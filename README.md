# Sri Saran — Developer Portfolio

A responsive futuristic portfolio made with plain HTML, CSS, and JavaScript.

## Run on your Mac
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or install the **Live Server** extension in VS Code.
3. Right-click `index.html` → **Open with Live Server**.

## Personalise before publishing
- In `index.html`, replace `your-email@example.com` with your email.
- Put your actual resume PDF in this folder and name it `resume.pdf`.
- Check the GitHub and LinkedIn links.
- Update any skills or project details to match your current experience.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` (or any repository name).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and `resume.pdf`.
3. For a normal repository: open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment and open the URL shown in Settings → Pages.

Note: this is a static portfolio, so no backend server is required.
